Andromeda

Andromeda - ваша утилита для быстрой диагностики компьютера с удобным GUI интерфейсом!
Andromeda предлагает
1)Диагностику CPU

2)Текущие процессы

3)Все данные о процессоре

4)Данные о ОС (название, версия, архитектура)

5)Загруженность диска

6)Текущую зарядку

У Andromeda открытый исходный код,написанный на языке Python на библиотеках PyQt6,psutil и system.
Вы можете быть уверены в безопасности кода.
